# 數位治理計畫|合作診所入口網

「從分級醫療到數位治理」計畫的合作診所官方網站(純前端靜態網站)。

## 頁面

| 頁面 | 說明 |
|------|------|
| 首頁 | 主視覺與功能導覽 |
| 收案儀表板 🔒 | 各院所收案達標率指針儀表(需通行碼) |
| 課程公告 | 課程資訊、海報與報名連結 |
| 教學手冊 | 教學影片與文件下載 |
| 合作診所 | 診所名單 + Google My Maps 地圖標記 |
| 活動花絮 | 活動照片牆 |
| 會議紀錄 🔒 | 會議紀錄/照片/簽到表(需通行碼) |

## 資料更新方式

網站內容由 Google 試算表驅動,**修改試算表後重新整理網頁即生效**,不需改程式:

- 收案數字 → 「KPI收案數據」試算表(新增日期欄放在目標欄右側)
- 課程 → 「課程公告」試算表
- 診所名單 → 「診所名單」試算表
- 會議 → 「會議紀錄」試算表

照片與檔案放 Google 雲端硬碟,分享連結貼入對應試算表欄位。
